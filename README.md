# Casebook

Short, dated reviews of things that change how n8n workflows and AI agents should be run in production. Each entry says what happened, what it changes for you, a check you can run yourself, what I would do, and where the facts come from.

## Entry types

- **Advisory review:** an upstream security update or a model or provider change.
- **Post-incident review:** a public incident or breach worth learning from.
- **Case study:** client work, published only with the client's written consent.
- **Worked diagnosis (example):** a diagnosis on a test system, labelled as an example throughout.
- **Drill report:** a rehearsed incident on a test system.
